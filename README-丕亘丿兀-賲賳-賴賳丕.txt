تطبيق الحرية المالية - مشروع Android
====================================

هذه الحزمة تحتوي على:
- واجهة التطبيق العربية RTL في index.html و www/index.html.
- إعداد Capacitor لتحويل التطبيق إلى Android.
- اختبارات لمنطق الحسابات والحركات المالية.
- GitHub Actions لبناء APK تلقائياً ورفع ملف APK كـ Artifact.

قبل البناء:
1) ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (وليس المجلد الخارجي نفسه).
2) تأكد أن الملفات والمجلدات التالية في جذر المستودع:
   package.json
   capacitor.config.json
   index.html
   www/index.html
   tests/
   .github/workflows/android.yml
3) افتح تبويب Actions في GitHub.
4) شغّل workflow باسم Android Build، أو ادفع commit جديداً إلى main.
5) انتظر حتى ينتهي البناء بنجاح.
6) افتح عملية البناء الناجحة، ثم Artifacts، ونزّل financial-freedom-debug-apk.
7) فك ضغط الملف على الهاتف وثبّت app-debug.apk. قد يطلب Android السماح بالتثبيت من هذا المصدر.

الاختبارات التي يمكن تشغيلها:
  npm install
  npm run test:finance

ملاحظات مهمة:
- هذه حزمة مصدر وبناء، وليست ملف APK جاهزاً.
- ملف APK الناتج من workflow هو Debug APK للتجربة والتثبيت اليدوي، وليس نسخة Play Store موقعة للنشر.
- بيانات التطبيق محفوظة محلياً على الجهاز. احفظ نسخة احتياطية قبل حذف التطبيق أو بياناته.
- لا يمكن ضمان خلو أي برنامج من جميع الأخطاء؛ يجب اختبار APK الناتج على الهاتف قبل الاعتماد عليه.
